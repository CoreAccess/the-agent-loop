# CMS Incubator Case Study

Date: 2026-05-02
Status: compact applied-evidence note

## Required Context

The separate CMS workspace began as an AI/agent-first CMS and website-factory idea. The useful center of gravity shifted toward The Agent Loop itself: a project-local operating system for AI coding agents.

The CMS idea is deferred. It may become a future applied vertical, but it is not the active product direction.

## Applied Lessons

- The central problem is helping a coding agent pursue large goals despite context-window limits, hidden assumptions, and fragile summaries.
- Self-application is only useful as a hypothesis loop. A rule should be researched, packaged into an isolated experiment, run in a fresh session, reviewed, and promoted only if it helped.
- Research must stay in the loop before major framework decisions are promoted.
- Raw experiment capsules should be temporary evidence. Distill the lesson, keep git history for raw detail, and avoid carrying bulky fixtures in the active repo.

## Evidence Preserved

- Experiment 001: passed 20/21. A fresh agent could convert trimmed research into source-anchored memory and a Goal, but the test was highly scaffolded.
- Experiment 002: passed 20/21. The markdown scaffold was coherent, but the same agent built and judged it.
- Experiment 003: passed 20/21. The actor loaded scaffold files, selected memory through the index, rejected unsafe/low-value candidates, handled contradiction, and stopped after the retrieval limit.
