# Documentation

This folder preserves research and evidence that informs The Agent Loop.

Use it just in time. Do not load the full docs tree unless the task needs broad historical context.

## Structure

- `research/` - source-backed research notes, category deep dives, and future-topic research seeds.
- `case-studies/` - distilled lessons from incubators, imports, validation runs, and self-application.

## Loading Guide

- For current project state, start with `.agent-loop/START.md` and `.agent-loop/project/`.
- For framework design decisions, load the relevant category folder under `docs/research/`.
- For evidence from prior applied work, load `docs/case-studies/`.
- For old raw experiment details, use git history rather than recreating the removed `experiments/` folder.

## Writing Guide

- Keep research notes source-backed and scoped to one category, source cluster, or decision area.
- Put validation summaries and applied lessons in `case-studies/`.
- Add or update an index when adding a new docs subfolder.
- Prefer compact summaries plus links to source notes over duplicating full historical logs.
