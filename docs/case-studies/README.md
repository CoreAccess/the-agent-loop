# Case Studies

Case studies preserve applied evidence and validation lessons without keeping raw workspaces in the active repository.

## Index

- `agent-loop-validation-lessons.md` - distilled lessons from Experiments 001-006 after raw experiment folders were removed.
- `agent-loop-v2-import.md` - lessons from sanitizing an applied `.agent-loop-v2` folder into the v0.2 release source.
- `cms-incubator.md` - lessons from the earlier CMS incubator that clarified The Agent Loop as the main project.

## Use

- Load case studies when deciding whether a rule has evidence behind it.
- Keep case studies compact and outcome-oriented.
- Preserve raw artifacts in git history or external validation workspaces rather than in this active repo.
