# Workflow Index

Load only the workflow file needed for the current mode or task.

- Intake or onboarding: `.agent-loop/workflows/intake.md`
- Broad planning or discovery after intent is accepted: `.agent-loop/workflows/planning.md`
- Active goal implementation: `.agent-loop/workflows/execution.md`
- Deleting files, symbols, or removed behavior: `.agent-loop/workflows/safe-deletion.md`
- Closing out meaningful work: `.agent-loop/workflows/reflection.md`

Use `.agent-loop/templates/` only when creating or replacing the matching project-state file.
