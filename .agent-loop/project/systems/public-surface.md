# Public Surface System

Status: accepted

## Function

Explain what The Agent Loop is, what version is active, and how users install it.

## Owned Files

- `README.md`
- GitHub Releases descriptions and uploaded ZIP assets.

## Rules

- Root `README.md` is the canonical public install guide.
- The package-local `.agent-loop/README.md` stays in release ZIPs so copied packages remain self-contained.
- Release notes should stay short unless a full changelog is explicitly needed.
- Warn users to download uploaded release ZIP assets, not GitHub's automatic source-code archives.
- Do not imply release ZIP files are tracked in this repository; they are generated and uploaded to GitHub Releases.
